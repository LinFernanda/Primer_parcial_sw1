# Primer Parcial - Software 1: Plataforma CASE Colaborativa Inteligente

Este repositorio contiene la solución completa de la **Plataforma CASE Colaborativa Inteligente para Diseño UML y Generación Automática de Software**.

## Estructura del Repositorio

- **`MANUAL_DE_USUARIO.md`**: Manual de usuario completo en formato Markdown con guías paso a paso, arquitectura, comandos de voz/IA, visión artificial y solución de problemas.
- **`ALCANCES_DEL_PROYECTO.md`**: Especificación formal exhaustiva de los alcances de la plataforma dividida en sus 13 módulos.
- **`software-case-platform/`**: Código fuente de la solución de ingeniería organizada por módulos:
  - **`backend/`**: API REST en Spring Boot 3 con Java 21 LTS y PostgreSQL 16.
  - **`frontend/`**: Cliente Web SPA en React 18 con TypeScript y Vite.
  - **`mobile/`**: Aplicación móvil en Flutter y Dart.
  - **`database/`**: Scripts de inicialización y esquemas de base de datos.
  - **`scripts/`**: Scripts de automatización para ejecución local.

Para consultar la guía paso a paso de uso de la aplicación, revise el [Manual de Usuario](MANUAL_DE_USUARIO.md).  
Para ver la documentación técnica y las guías de inicio, consulte el [README de software-case-platform](software-case-platform/README.md).
